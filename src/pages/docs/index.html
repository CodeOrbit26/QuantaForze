1. Quickstart & Installation

Install the QuantaForze command-line tools and TypeScript SDK packages globally via npm or pnpm: 

# Global Installation
npm install -g @quantaforze/cli @quantaforze/sdk

# Initialize Workspace
quantaforze init --template agentic-workspace

2. CLI Commands

The QuantaForze CLI provides keyboard-first execution and trajectory debugging directly in your terminal:

    quantaforze run "prompt" — Execute an autonomous multi-step execution loop.
    quantaforze status — Inspect active background worker pools and agent trajectory logs.
    quantaforze verify — Run verification suites across codebase changes before approval.

3. TypeScript SDK Example

import { QuantaAgentEngine, WorkspaceHarness } from '@quantaforze/core';

const harness = new WorkspaceHarness({
  workspacePath: '/Users/dev/my-project',
  maxParallelWorkers: 4,
  verificationCommand: 'npm test'
});

const agent = new QuantaAgentEngine({
  model: 'gemini-3.6-flash',
  harness: harness
});

const result = await agent.executeGoal({
  prompt: 'Refactor auth middleware to support OAuth2 JWT tokens',
  requireApproval: true
});

console.log('Execution Trajectory Completed:', result.success);
