Enterprise Architecture & Tech Stack

Production Monorepo

Engineered for extreme performance, sub-millisecond WebSocket notifications, and reliable campus scale.

📱 Flutter Mobile Client

  • Feature-first Clean Architecture with Riverpod
  • Material Design 3 with adaptive layouts for phones & tablets
  • STOMP WebSocket client with exponential backoff reconnect
  • Optimistic feed rendering and offline caching

⚙️ Kotlin & Spring Boot Core

  • Spring Boot 3.3.x enterprise core running on JDK 21
  • 17 domain modules: Posts, Clubs, Events, Leaderboards, Chat
  • Spring Security + Firebase Admin Token Filter with RBAC
  • Kafka event streaming for notifications & async fanouts

🗄️ Database & Cloud Infra

  • PostgreSQL transactional database with 13 Flyway SQL migrations
  • Redis for sliding-window rate limiting & distributed locks
  • Elasticsearch full-text search across projects and profiles
  • AWS S3 pre-signed URLs for certificate & asset uploads
