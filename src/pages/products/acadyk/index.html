Enterprise Architecture & Tech Stack

Production Monorepo

Engineered for extreme performance, low latency notifications, and thousands of concurrent campus interactions.

📱 Flutter Mobile Client

  • Feature-first Clean Architecture with Riverpod state management
  • 100% responsive across Android phones, tablets, and web browsers
  • STOMP WebSocket client with automatic reconnection & exponential backoff
  • Offline caching & instant feed optimistic updates

⚙️ Kotlin & Spring Boot Core

  • Spring Boot 3.3.x enterprise backend running on JDK 21
  • 17 domain modules: Posts, Clubs, Events, Leaderboard, Chat, Coins
  • Spring Security + Firebase Admin JWT Token Filter
  • Apache Kafka event streaming for real-time notifications & fanouts

🗄️ Database & Cloud Infra

  • PostgreSQL ACID transactional database with 13 Flyway SQL migrations
  • Redis for caching, sliding-window rate limiting & distributed locks
  • Elasticsearch autocomplete & full-text search across projects & posts
  • AWS S3 pre-signed URLs for ultra-fast certificate & image uploads
