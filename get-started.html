Get Started with QuantaForze

Deploy your first autonomous AI agent, set up device connectivity, or integrate the Intelligence Layer in under 5 minutes.

01

Install QuantaForze CLI & SDK

Install the official QuantaForze Command-Line Interface and developer SDK using your preferred package manager.

npm install -g @quantaforze/cli @quantaforze/sdk
02

Initialize Project & Authenticate

Navigate to your project directory and create a new QuantaForze configuration file with your API credentials.

quantaforze init --template agentic-workspace
03

Run Your First Autonomous Agent Task

Dispatch intent to your autonomous agent harness and watch parallel worker execution loops in action.

quantaforze run "Analyze repository and generate automated architecture plan"
