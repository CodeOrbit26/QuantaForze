# QuantaForze Production Web Platform

Production-grade frontend codebase for QuantaForze Technologies Inc.

## Architecture

- `public/`: Static assets (images, icons, fonts).
- `src/pages/`: Page-specific source code & assets.
- `src/components/`: Reusable UI components (header, footer, navigation).
- `src/styles/`: Modular CSS hierarchy (base, components, pages, utilities).
- `src/scripts/`: Component & core JavaScript logic.
- `dist/`: Built production bundle.

## Development & Build

```bash
# Run local dev server
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```
