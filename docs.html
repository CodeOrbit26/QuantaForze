QuantaForze Documentation

QuantaForze is an agentic development platform designed for building, orchestrating, and executing autonomous parallel AI agents with zero-friction harness pipelines.

💡
Powered by Gemini 3.6 Flash: QuantaForze integrates seamlessly with Google Gemini 3.6 Flash & Advanced Harness primitives for high-speed multi-file code editing.

Quickstart (5-Minute Setup)

Get your first autonomous coding agent up and running in under 5 minutes using the official CLI tool:

bash 
# Install QuantaForze CLI globally
npm install -g quantaforze-cli

# Initialize a new agentic workspace
quantaforze init my-agent-workspace

# Start an autonomous coding agent task
quantaforze run --goal "Build a high-performance LRU cache in Rust with 100% test coverage"

Installation & Prerequisites

Make sure your machine meets the following requirements before installing QuantaForze:

  • Node.js: v18.0.0 or higher
  • Package Manager: npm v9+, pnpm, or yarn
  • Operating System: macOS (ARM64 / x86), Linux, or Windows (WSL2)

Installing via Package Manager

bash 
npm install @quantaforze/core @quantaforze/harness

Architecture Overview

QuantaForze decouples high-level task planning from low-level file mutation through a 4-stage harness loop:

01

Planning Engine

Generates structured implementation_plan.md documents with explicit user review checkpoints.

02

Parallel Harness

Executes multi-file changes concurrently across isolated workspace threads with lock safety.

03

Verification Loop

Runs automated unit tests, build commands, and lint checks before confirming completion.

04

Walkthrough Engine

Produces detailed walkthrough.md artifacts with visual proof and test output logs.

Node.js / TypeScript SDK

Import and instantiate parallel agents directly inside your TypeScript application:

typescript 
import { QuantaAgentEngine, WorkspaceHarness } from '@quantaforze/core';

const harness = new WorkspaceHarness({
  workspacePath: '/Users/dev/my-project',
  maxParallelWorkers: 4,
  verificationCommand: 'npm test'
});

const agent = new QuantaAgentEngine({
  model: 'gemini-3.6-flash',
  harness: harness
});

// Run an autonomous task
const result = await agent.executeGoal({
  prompt: 'Refactor auth middleware to support OAuth2 JWT tokens',
  requireApproval: true
});

console.log('Execution completed:', result.summary);
